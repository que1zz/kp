# kp
## Постановка задачи

Датчик технологической установки непрерывно формирует последовательность показаний давления инертного газа в реакторе X (диапазон значений от 1 до 8 бар). В программной реализации 70 показаний последовательно считываются из файла. Каждое показание X преобразуется по индивидуальной кусочной функции в индикатор технологического процесса Q: при X < 2 применяется формула (X−2)² + 10, при 2 ≤ X ≤ 5 — формула 3·(X−3.5) + 50, при X > 5 — формула 2·√(X−5+1) + 60.
